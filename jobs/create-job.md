# Create Job

## Purpose

The Create Job feature allows users to generate and publish new job requirements using AI-assisted job creation methods. Users can create jobs by interacting with AI, providing prompts, uploading existing job descriptions, or pasting job content directly into the system.

Once a job is created, it becomes available in the Jobs list and can be used for candidate sourcing, submissions, and recruitment tracking.

---

## Intended Users

The Create Job feature is available to:

* Account Manager
* Delivery Manager
* Technical Recruiter

Users must have access to the selected Business Unit to create jobs.

---

## Accessing Create Job

### Navigation Flow

```text
Login
    ↓
Select Business Unit
    ↓
Jobs
    ↓
Add Job
```

Selecting **Add Job** opens the job creation interface.

---

## Available Job Creation Methods

Users can choose from the following job creation methods:

### Chat with AI

Allows users to create a job by answering AI-generated questions.

The AI collects hiring requirements and generates a structured Job Description.

### Write Prompt

Allows users to describe the hiring requirement using a text prompt.

The AI analyzes the prompt and generates a Job Description.

### Upload JD

Allows users to upload an existing Job Description file.

The AI extracts relevant information and generates a structured Job Description.

### Paste JD

Allows users to paste an existing Job Description directly into the system.

The AI analyzes the content and generates a structured Job Description.

---

## AI-Generated Job Description

After processing the provided information, Glohire ATS generates a Job Description.

Users can review the generated content before proceeding.

### Available Actions

#### Edit

Allows users to modify the generated Job Description directly within the ATS.

Users can update responsibilities, skills, qualifications, and other job details before continuing.

#### Continue

Allows users to proceed with job creation using the generated Job Description.

---

## Complete Job Information

After selecting **Continue**, users must provide the following information.

### Client Name

Select the client associated with the job requirement from the available client list.

### Client POC

Specify the client Point of Contact.

Users can:

* Select an existing POC
* Enter a POC manually

### Client Bill Rate Value

Enter the bill rate amount associated with the job requirement.

### Client Bill Rate Currency

Select the applicable currency.

Supported currencies include:

* USD
* INR
* EUR
* GBP
* AUD
* CAD
* JPY
* CNY
* CHF
* SGD
* HKD
* NZD
* SEK
* KRW
* RUB
* QAR
* SAR
* AED
* BHD
* KWD

### Client Job Type

Select the job type.

Available options:

* Full-Time
* Contract
* Part-Time
* Contract to Hire

### Client Bill Pay Rate Cycle

Select the billing cycle.

Available options:

* Weekly
* Biweekly
* Monthly
* Annually

---

## Create Job

After completing all required information, the system creates the job requirement.

The newly created job is automatically added to the Jobs list.

Users can immediately begin recruitment activities for the job.

---

## Outcome

After successful job creation, users can:

* View the job in the Jobs list
* Launch Candidate Discovery
* Tag Candidates
* Manage Pipeline Activities
* Submit Candidates
* Track Recruitment Progress
