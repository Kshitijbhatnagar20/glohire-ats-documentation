# Jobs Overview

## Purpose

The Jobs Module is the central workspace for managing job requirements within Glohire ATS. It enables recruiters and hiring teams to create, manage, track, and fulfil client hiring requirements through AI-assisted job creation and recruitment workflows.

The module acts as the starting point of the recruitment lifecycle, connecting client requirements with candidate sourcing, submissions, and hiring activities.

---

## Intended Users

The Jobs Module is accessible to:

* Account Manager
* Delivery Manager
* Technical Recruiter

Users can perform actions based on their assigned permissions and Business Unit access.

---

## Accessing the Jobs Module

### Navigation Flow

```text
Login
    ↓
Select Business Unit
    ↓
Jobs
```

All job requirements displayed are associated with the selected Business Unit.

---

## Jobs Page Layout

The Jobs page provides recruiters with visibility into all active and historical job requirements.

Users can:

* View all jobs
* Search jobs
* Filter jobs
* Create new jobs
* Manage recruitment activities for individual jobs

---

## Job Filters

The Jobs page includes the following filtering options:

### Search

Allows users to locate jobs using keywords.

### Draft Jobs

Displays jobs that have been saved as drafts and are not yet active.

### Time Frequency

Filters jobs based on creation or activity timelines.

### Status

Displays jobs based on their current status.

---

## Creating a Job

Users can create a new job by selecting **Add Job**.

Glohire ATS supports multiple AI-assisted job creation methods.

### Chat with AI

Users answer AI-generated questions about the hiring requirement.

The system uses the responses to generate a Job Description.

### Write a Prompt

Users provide a hiring prompt describing the requirement.

The AI processes the prompt and generates a Job Description.

### Upload or Paste JD

Users can upload an existing Job Description or paste job content directly.

The system analyzes the information and generates a structured Job Description.

---

## Completing Job Information

After the Job Description is generated, users are required to provide:

* Bill Rate
* Client Type
* Client Name
* Client POC

Once completed, the job is created and added to the Jobs list.

---

## Job Actions

Each job contains quick-access actions that support recruitment activities.

### Candidate Discovery

Provides access to candidate sourcing capabilities.

### Notes

Allows users to create and manage job-specific notes.

### Pipeline

Displays candidate progress through recruitment stages.

### Submission

Provides access to candidate submission activities.

### Active / Inactive Status

Allows users to activate or deactivate a job requirement.

---

## Additional Actions

The following actions are available for individual jobs:

### Create Job Summary

Generates a summarized version of the job requirement.

### Tag Candidate

Associates candidates with a specific job requirement.

### Mail

Provides access to job-related communication options.

### Edit Job

Allows modification of job details.

### Delete Job

Removes a job from the system.
